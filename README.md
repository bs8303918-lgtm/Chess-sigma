## Sigma Chess

Шахматная платформа с геймификацией и AI-фичами: играй **онлайн / локально / с ботом**, получай **бесплатный AI review**, **персональные ранги**, оценки от **мемного AI Judge** и собирай **коллекционные карточки**.

## Возможности

- **Игра**
  - **Online**: игра с другими игроками
  - **Local**: партия на одном устройстве
  - **AI Bot**: тренировка против движка (Stockfish)

- **Бесплатный AI Game Review**
  - **Фото/скрин**: вставляешь картинку(и) партии/позиции → получаешь разбор
  - **Chess.com**: вводишь никнейм → сайт делает review твоих партий без подписок

- **Эволюционная ранговая система**
  - AI выдает **индивидуальное звание** по твоему ELO
  - по мере роста рейтинга звание **эволюционирует**

- **AI Sigma Judge**
  - мемный судья, который ставит **оценку** и дает вердикт по твоей игре

- **Карточная система**
  - выигрывай партии и **собирай коллекцию карточек**

## Технологии

- **Next.js** (App Router)
- **Supabase** (авторизация/данные)
- **Stockfish** (бот/анализ)
- Интеграции AI (через переменные окружения)

## Быстрый старт

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

## Environment

Создай `.env.local` на базе `.env.example` и заполни ключи:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `OPENAI_API_KEY` (для review/rank/judge)
- `GEMINI_API_KEY` (для rank/judge)
